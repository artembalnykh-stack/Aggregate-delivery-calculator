КАЛЬКУЛЯТОР ДОСТАВКИ — «Нейростройтранс»
Инструкция по установке на Mac
════════════════════════════════════════════════════════════════

СПОСОБ 1 — ZIP-АРХИВ (рекомендуется, права администратора не нужны)

1. Распакуйте архив в удобную папку (например, «Документы» или
   рабочий стол). Появится папка «Калькулятор доставки» с приложением
   «КалькуляторДоставки.app» и папкой данных «data».
2. Дважды щёлкните «КалькуляторДоставки.app». Через 1–2 секунды
   откроется окно программы.
3. Если macOS предупредит о «неустановленном разработчике»:
   правый клик по «КалькуляторДоставки.app» → «Открыть» → «Открыть».
   Это одноразовое подтверждение, другие запуски пройдут без вопросов.
4. Полное выключение программы: Настройки → «⏻ Завершить приложение».

ВАЖНО: держите приложение и папку data вместе — база цен, история
расчётов и наряд-заказы хранятся в папке data рядом с приложением.

СПОСОБ 2 — УСТАНОВЩИК .PKG (устанавливает в /Applications)

1. Откройте «КалькуляторДоставки_установщик.pkg» и следуйте шагам
   установщика (нужен пароль администратора).
2. Программа установится в «Программы/КалькуляторДоставки».
   Запуск — двойным щелчком по «КалькуляторДоставки.app».
3. Если установщик предупредит о неизвестном разработчике:
   правый клик по файлу .pkg → «Открыть» → подтвердите.


СИСТЕМНЫЕ ТРЕБОВАНИЯ
────────────────────────────────────────────────────────────────
• macOS 12.0 (Monterey) или новее, процессор Intel или Apple Silicon.
• ~400 МБ свободного места (приложение + база + запас на архив прайсов).
• Chrome, Chromium или Microsoft Edge — интерфейс открывается отдельным
  окном; если ни один не установлен — вкладка любого браузера.
• Интернет нужен ТОЛЬКО для кнопки «Обновить прайс» (Яндекс Диск).
  Без интернета все остальные функции работают локально.


КУДА УСТАНАВЛИВАТЬ МОЖНО
────────────────────────────────────────────────────────────────
• Домашняя папка и её подпапки: «Документы», «Рабочий стол»,
  «Загрузки» — лучший выбор.
• /Applications (это делает установщик .pkg).
• Любая папка на локальном диске с правами на запись.

КУДА УСТАНАВЛИВАТЬ НЕЛЬЗЯ / НЕ РЕКОМЕНДУЕТСЯ
────────────────────────────────────────────────────────────────
• ЗАПРЕЩЕНО: системные папки (/System, /Library, /private) — macOS
  защищает их, приложение не сможет писать свои данные.
• НЕ РЕКОМЕНДУЕТСЯ: папки iCloud Drive — облако выгружает файлы данных
  на сервер и «замораживает» их локально; при запуске база может
  отсутствовать или быть неактуальной.
• НЕ РЕКОМЕНДУЕТСЯ: сетевые диски (SMB/NFS/общие папки) — риск порчи
  базы истории расчётов.
• НЕЛЬЗЯ: смонтированные носители без записи (образ диска, read-only
  том) — данные невозможно создать рядом с приложением.
• Для Windows этот пакет не предназначен: там нужна отдельная сборка
  на компьютере с Windows.


ПЕРЕДАЧА НА ДРУГОЙ КОМПЬЮТЕР
────────────────────────────────────────────────────────────────
• Передавайте исходный ZIP-архив как есть (AirDrop, флешка, почта,
  облако) и распаковывайте стандартным способом macOS.
• НЕ перепаковывайте архив средствами Windows: это ломает симлинки
  внутри .app, и приложение перестаёт запускаться.
• Если получатель скачал архив через браузер и macOS добавила карантин:
  первый запуск после «правый клик → Открыть» решает вопрос.

Возникла проблема? Откройте файл data/app.log — туда записаны все шаги
запуска приложения.
