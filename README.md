# Калькулятор стоимости заказа с доставкой — «Нейростройтранс» (MVP)

Локальное приложение для менеджеров по продажам стройматериалов: расчёт
стоимости заказа с учётом объёма, вместимости самосвалов, числа рейсов,
минимальных объёмов, самовывоза и порогов бесплатной доставки. Результат —
заказ-наряд в формате Word.

**Все данные хранятся на компьютере менеджера. Ничего не уходит в интернет,
кроме явной загрузки прайса по ссылке Яндекс Диска.**

---

## Как это работает (архитектура)

```
┌─────────────┐   JSON    ┌──────────────────┐
│  Браузер     │ ◄──────► │  Python (Flask)   │
│  HTML/CSS/JS │  127.0.0.1│  generate-ядро    │
└─────────────┘           └───────┬──────────┘
                                  │ читает ТОЛЬКО
                          ┌───────▼──────────┐
                          │  data/прайс.xlsx  │  ← единственный источник данных
                          │  data/exports/    │  ← готовые заказ-наряды Word
                          │  data/history     │  ← SQLite история расчётов
                          └───────────────────┘
```

- **src/parser/** — парсинг Excel: сам находит листы и строку шапки, сопоставляет
  колонки («Цена, руб» ≠ «цена», но понимает), проверяет типы. Некорректный
  файл применяется целиком или отклоняется.
- **src/core/** — расчётное ядро (`Decimal`, без UI): объём, масса, подбор
  машин, тарифы. Покрыто тестами.
- **src/server/** — локальный Flask + сервисы: добавление товара в прайс,
  скачивание прайса с Яндекс Диска, настройки.
- **src/docgen/** — заказ-наряда Word (OOXML через python-docx).
- **src/storage/** — история расчётов в SQLite (снимки цен, история
  не пересматривается задним числом).
- **src/web/** — интерфейс (одна страница, без внешних CDN, работает офлайн).

## Бизнес-правила расчёта

| Правило | Где задаётся |
|---|---|
| Расстояние = прямая по координатам × коэф. (1,35) | Правила |
| Режим обратного пути («Туда и обратно»/«Только туда») — видно в UI и в документе | Правила |
| Стоимость рейса = базовый тариф + тариф/км × расстояние | Тарифы |
| Рейсы = max(по весу, по объёму ÷ объём кузова × коэф. наполнения) | Самосвалы |
| Доставка = Σ рейсов × стоимость рейса, но не меньше минимума | Тарифы |
| Сумма заказа ≥ порога → доставка бесплатна | Тарифы |
| Самовывоз: доставка = 0, транспорт не назначается | — |
| Машина допускается только при «Вышел на линию» = Да и «Исправна» = Да | Самосвалы |
| Оптимум: минимум стоимости → минимум рейсов → минимум машин | — |
| Если рейсов больше лимита смены — подключается вторая машина | Тарифы |
| Расстояние — оценочное, по прямой: UI и Word показывают предупреждение | — |

## Быстрый старт (разработка, macOS)

```bash
cd calculator_2
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python src/main.py     # поднимет сервер и откроет окно браузера
```

## Сборка .app (macOS)

```bash
build/build_app.sh
# → dist/КалькуляторДоставки.app + dist/data/
```

- Данные лежат **рядом с .app** (`dist/data`), правьте прайс без пересборки.
- Первый запуск: правый клик → «Открыть» (Gatekeeper для неподписанного
  приложения; отключать защиту не требуется).
- Окно Chrome/Safari без адресной строки открывается автоматически.

## Наряд-заказы: где взять Word-документ

Менеджер заходит в раздел **🧾 Наряд-заказы** — там список всех созданных
документов (`.docx`) с датой и размером. Кнопка **⬇ Скачать** сохраняет файл
на компьютер (обычно в «Загрузки»), имя файла сохраняется. Кнопкой «Удалить»
ненужные документы убираются из списка. Исходники лежат локально в
`data/exports/`.

## Обновление цен кнопкой «Обновить»

Механика:
1. Менеджер открывает **Настройки** или раздел **Наряд-заказы → Обновление цен**
   и вставляет ссылку на Яндекс-таблицу (по умолчанию поле пустое).
2. Кнопка **🔄 Обновить** скачивает актуальный файл с Яндекс Диска
   (документированный публичный API, без паролей и токенов),
   полностью проверяет его парсером и **заменяет локальную базу** `data/прайс.xlsx`.
3. Прежняя база автоматически сохраняется в `data/archive/` с меткой даты-времени;
   в архиве хранятся **10 последних** копий, более старые удаляются.
4. Из архива можно вернуть любую копию кнопкой «Вернуть эту»: текущий прайс
   при этом тоже уходит в архив — данные не теряются.

## Первый запуск (macOS)

Приложение живёт по схеме «трамплин»: двойной клик стартует короткий процесс,
который поднимает фоновый сервер и сразу открывает окно интерфейса в Chrome,
затем завершается — впадение в «не отвечает» невозможно, ожидания в Dock нет.

- Двойной клик по `.app` → через 1–2 секунды появляется окно.
- Повторный двойной клик → ещё одно окно интерфейса (сервер один, экземпляр
  не плодится).
- Полное выключение: **Настройки → «⏻ Завершить приложение»**.
- Причины любого сбоя видны в `data/app.log`.

Если Finder предупредит о «неустановленном разработчике» (на другом Mac):
правый клик по `.app` → «Открыть» → «Открыть».

## Демонстрационный сценарий (2–3 минуты)

1. Откройте приложение — главная «Калькулятор» с предзаполненным заказом
   (склад Москва-Юг → Москва, ЮАО, 10 м³ песка).
2. Нажмите **Рассчитать** — итого с доставкой крупным шрифтом,
   назначен КамАЗ, показано число рейсов и предупреждение о прямой.
3. Измените количество (например, 60 м³) → повторно рассчитать:
   видно подключение второй машины (лимит рейсов за смену).
4. Переключитесь на **Самовывоз** → рассчитать: доставка = 0, машины нет.
5. Откройте **Автопарк** — покажите статусы «На линии» и «Исправна».
6. Вернитесь, увеличьте заказ больше порога бесплатной доставки
   (180 000 ₽) → доставка бесплатна.
7. **📄 Заказ-наряд Word** — документ в `data/exports/`: таблицы позиций,
   транспорт, итоги, предупреждение о расстоянии.
8. **История** — откройте ранний расчёт: цены в нём прежние
   (снимок на момент расчёта), кнопка повторного Word-документа.
9. **Настройки** — ссылка Яндекс Диска, кнопка «Скачать актуальный прайс»,
   показ даты и состава данных.

## Формат внешнего прайса

Файл `data/прайс.xlsx` содержит листы (шапку программа находит сама,
она может быть сдвинута в глубь листа):

| Лист | Обязательные колонки |
|---|---|
| Товары | Артикул, Наименование, Категория, Единица измерения, Цена ₽, Масса единицы кг, Объём единицы м³, Тип груза, Активен |
| Самосвалы | ID, Модель, Госномер, Тип кузова, Грузоподъёмность т, Объём кузова м³, Коэф. наполнения навалочные/штучные, **Вышел на линию**, **Исправна** |
| Склады | ID, Название, Город, Адрес, Широта, Долгота |
| Пункты доставки | ID, Название, Широта, Долгота |
| Тарифы | Параметр / Значение (базовый тариф, ₽/км, минимум, порог бесплатной, макс. рейсов, мин. объём) |
| Правила | Параметр / Значение (коэф. прямой, режим обратного пути, округление) |
| Совместимость | Тип груза × Тип кузова → Допустимо |

## Второй этап (задел уже есть)

- Обновление **только цен товаров** из Яндекс Таблиц: в приложении цены
  изолированы (снимок на расчёт), парсер товаров отделён от справочников.
- Сейчас прайс грузится с Яндекс Диска целиком по публичной ссылке
  (публичный API, без токенов), с проверкой файла до замены.

## Известные ограничения

- Демо-данные вымышленные («выглядят реалистично»), редактируются в Excel.
- Расстояние — по прямой × коэффициент, **не** фактический маршрут (UI
  и документ честно предупреждают).
- Подбор машин — жадная эвристика при комбинации (минимум стоимости,
  затем рейсов, затем машин); строго оптимальный LP не заявляется.
- У товара без объёма объёмная проверка недоступна — показывается
  предупреждение, расчёт идёт по весу.
- Сборка Windows .exe с macOS невозможна технически; при необходимости
  запускается по инструкции на Windows-машине (та же команда PyInstaller).
- Первый расчёт после запуска занимает ~5 с (загрузка и разбор прайса).

## Резервное копирование

Скопируйте папку `data/` целиком — в ней прайс, история (SQLite) и
готовые документы. Восстановление = возврат папки на место.
